# Editing overview

Pages are drafts until someone submits them. The editor and the assistant change the same page model: a list of approved blocks, such as a hero, text, a gallery, or a donation embed.

The assistant does not write HTML or JavaScript. It assembles blocks the site already allows. Custom CSS on a section, when it is offered, goes through the same checks as a person's edit, and a person still has to approve it.

A new page starts from a page type. The page type says which blocks are allowed and which ones the page must include. Images come from the media library. The builder makes smaller copies when you upload, so the published page does not serve the original file.

Donation and payment forms are embeds from a provider you already use, such as Virtuous. Skewstone does not take payments itself.
