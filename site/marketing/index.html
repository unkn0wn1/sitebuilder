A fast website you own

Staff describe the page they want. Skewstone drafts it from the site's approved blocks. A person approves it, and the site publishes as static HTML on a server you control.

Try the demo Read the docs

How a page gets made

Someone says what the page is for. The assistant asks a few questions, then builds a draft only from the blocks and brand already allowed on the site. It does not write HTML or JavaScript. You go back and forth until the draft looks right. A person with approval rights checks it and publishes.

Underneath, the public site is ordinary static HTML. nginx serves it. Cloudflare sits in front. One small server is enough to run the builder and the published files.

What it does not do

Skewstone does one job: build and update a fast website. These are left out on purpose.

  • No open plugin marketplace. Plugins come from a small curated catalogue, each one signed by the Skewstone maintainers. Nothing third-party, and nothing is installed unless an admin chooses it.
  • No payments and no shop. Donation forms are embedded from a tool you already use.
  • No accounts for visitors, and no comments or forums.
  • No built-in CRM or email marketing.
